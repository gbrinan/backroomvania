# 제13종의 밤 — 약 50분 호러 어드벤처 설계

2026-09-13 · 기획 반영, 런타임 미구현

사용자 확정 방향: 고딕 다크 판타지 호러 어드벤처, 약 50분, 쉬운 조작, 초반 코어 재미 체험, 점진적 확장, 퍼즐보다 직접적인 행동, 가벼운 개그. 아래 시간·수치·배치는 이 방향을 구현하기 위한 설계 목표이며 플레이테스트로 검증할 가설이다. 세계관·반전 정본은 [전체 이야기](../narrative/full-story.md), 결정 이유는 [0009](../decisions/0009-fifty-minute-adventure.md)를 따른다.

## 한눈에 보는 경험

**다가오는 위험을 비키고 → 짧게 반격하거나 지나치고 → 사람이나 유물을 구하고 → 새 힘으로 익숙한 길을 돌파한다.**

플레이어는 암호를 해독하는 사람이 아니라, 무서운데도 한 발 더 나아가는 기록복원사다. 기본 공격과 회피는 끝까지 그대로다. 달라지는 것은 버튼 수가 아니라 적의 움직임, 지나갈 수 있는 길, 상황을 해결하는 여유다.

공포는 일상의 붕괴·백룸의 불가능한 거리·추적자의 예고로 만든다. 무한 체력의 적, 강제 대기, 반복 왕복으로 시간을 채우지 않는다. 액션 1~2분 뒤 15~30초의 발견·대화·안도 구간을 두며, 전 구간에 적을 채우지 않는다.

## 50분의 본편 동선

기준: 처음 플레이하는 사람이 일반 엔딩까지 진행하는 약 50분. 짧은 대화·전환·가벼운 재시도 여유를 포함한 편성이다. 일시정지·자리 비움은 제외한다. 목표 관측 범위 45~60분이며 현재 배포본의 실측 시간이 아니다. 고양이와 선택 퀘스트를 적극적으로 찾으면 약 3~7분 추가를 예상한다.

| 시간 | 공간과 사건 | 직접 하는 행동 / 재미의 확장 | 보상·다음 연결 |
| --- | --- | --- | --- |
| 0~6분 | 위층 사무실 → 지하 수장고 → 관장실 → 잭의 복도 → 열람실 | 유물 두 점 정리, 운반 수레 밀기, 거울 옮기기, 비명 뒤 귀환, 잭의 큰 베기를 옆으로 회피하고 수레로 길 막기 | 이동·조사·회피를 익힘. Rhast와 Trash 추적 동기. 안전한 거점과 검 |
| 6~11분 | 이집트 명문 복도·매장실·심판실 | 느린 풍뎅이 한 마리로 공격 연습 → 두 마리 사이로 빠져나가기 → 돌진을 비켜 경비원의 관 열기 | 사자의 서. 같은 회피로 얕은 물과 틈을 넘음 |
| 11~17분 | 침수 백룸 → 그리스 미궁 → 관장실 귀환 지름길 | 방금 배운 회피로 수면 건너기, 반사 속 거리 확인, 미노타우로스가 기둥을 들이받게 비키기, 빌리 구조, 홈즈의 첫 조언 | 도기가 실제 귀환길을 자동 표시. 빌리가 리볼버 제공. 이전 복도로 30초 안에 돌아옴 |
| 17~21분 | 아시리아 문지기·명령석·거울 복도 | 바람이 멎는 순간 전진, 눈앞의 잘못된 명령석을 한 번 조사해 수호자 진정, 잭의 거울 통로를 잠금 | 라마수 인장. 봉인문 앞 조사로 자동 해제. 도망치던 복도가 안전한 길이 됨 |
| 21~27분 | 중국 운송 회랑 → 인도 연꽃 연결실 → 일본 연회 | 수레 뒤로 숨으며 전진, 느린 바람 공격을 비켜가기, 구르는 술통 뒤따르기, 오니를 지나 두루마리 회수. 루팡 합류 | 지팡이 선택지와 그림 두루마리. 먹빛 시야가 가까운 진짜 문·숨은 발자국을 자동으로 드러냄 |
| 27~31분 | 한국 기록실·마당·천부인 내실 | 도깨비의 크게 휘두르는 방망이 뒤로 회피, 흩어진 인장 세 조각을 짧은 마당 동선에서 줍기, 내실 조사 | 천부인 자동 장착. 회피 직후 가까운 환영이 잠깐 고정되는 새 반격 기회 |
| 31~36분 | 강변 창고·런던 브리지 전경 → 안데스 석교 → 아즈텍 의례실 | 루팡이 연 문으로 수송로 이동, 사라짐이 예고된 발판 건너기, 재규어의 도약 피하기, 천부인으로 드러난 칼 회수 | 아즈텍 심장적출검이 검 슬롯을 강화. 안데스는 별도 문화 구역으로 유지 |
| 36~40분 | 열람실 짧은 재방문 → 비밀 수장고 | 기존 능력으로 가까운 지름길 통과, 선택 퀘스트 전달, 수집가와 짧게 대치. 연결이 드러날 때 공격해 조종을 끊음 | Trash = 인간 HAster, 홈즈에게 조종당했다는 반전. 여섯 유물의 용도가 하나로 모임 |
| 40~42분 | 겹쳐진 사건 회랑 | 루팡이 증거를 펼침. 이미 본 단서가 붙은 장면을 조사해 거짓 재현을 벗기고, 젖은 발자국을 따라 진짜 홈즈 쪽으로 이동 | 첫 승부: 머리. 암기 시험 없이 플레이어가 직접 모순을 확인 |
| 42~46분 | 런던 브리지 → 빅벤 → 대성당 접근로 | 느린 방해꾼은 지나치기, 가짜 홈즈는 발자국·물보라로 구별, 종의 예고에 맞춰 회피. 짧은 추격 3구간 사이 재시작 지점 | 두 번째 승부: 컨트롤. 앞에서 배운 행동을 연속 사용 |
| 46~50분 | 웨스트민스터 대성당 → 새벽 | 예고를 피하고 열린 틈에 반격하는 3단계 결전 약 3분 30초, 결말 약 30초 | 세 번째 승부: 근성. 천부인+심장적출검으로 타격. 왓슨 유물이 있으면 내면의 홈즈를 깨워 하스터만 추방 |

합계 6+5+6+4+6+4+5+4+2+4+4 = **50분**. 중국·인도·안데스는 짧고 특징적인 연결 모험, 이집트·그리스·일본·한국·아즈텍은 유물 획득의 중심으로 밀도를 달리한다. 모든 공간을 같은 길이의 던전으로 확장하지 않는다.

기존 19개 방은 지역 앵커로 사용한다. 한 방에서 오래 버티게 만드는 대신 이집트·그리스·일본 등에 짧은 연결 장면을 추가한다. 총 28~32개 플레이 장면을 작업용 상한으로 두되, 방 수 자체를 분량 보증으로 삼지 않는다. 장면당 하나의 주행동만 배치한다.

## 처음 6분: 설명창 대신 행동으로 가르친다

| 구간 | 화면에서 벌어지는 일 | 배우는 조작 | 성공·실패 대응 |
| --- | --- | --- | --- |
| 0:00~0:40 | 관장이 가까운 책상 위 유물을 가리킨다. 목표는 한 줄만 표시 | WASD / 방향키 이동 | 길막·피해 없음. 움직이기 전에는 다음 설명을 띄우지 않음 |
| 0:40~1:30 | 목록 카드를 조사하자 정돈된 받침과 작은 완료 소리. 두 번째 물건은 조금 떨어져 있음 | E 조사 | 키 한 번으로 완료. 읽기 시험·정렬 퍼즐 없음 |
| 1:30~2:30 | Trash 대화 뒤 지하로. 수레 옆에서 E를 누르면 이동 방향으로 밀 수 있고 다시 E로 놓음 | 같은 E의 맥락 행동 | 떨어뜨리거나 끼워도 복구 위치로 돌아옴. 운반 중 공격 없음 |
| 2:30~3:30 | 거울 이동, 바람, 소등, 비명. 계단에 비상등이 켜지고 관장실에서 Rhast 발견 | 익힌 이동·조사 재사용 | 이야기 핵심은 짧은 연출. 상세 기록은 선택 읽기 |
| 3:30~4:20 | 잭이 먼 거리에서 길게 칼을 들고, 바닥에 넓은 예고가 나타남 | Space 회피 | 첫 공격은 빗나가도록 여유 배치. 실패 시 가까운 복도에서 재시도 |
| 4:20~5:20 | 다음 베기를 비키고 운반 수레를 밀어 잭을 늦춘 뒤 문으로 달림 | 이동+회피+E 결합 | 수레는 회피 실패를 만회하는 안전장치. 잭을 쓰러뜨릴 필요 없음 |
| 5:20~6:00 | 루팡의 봉인이 붙은 안전문, 따뜻한 조명, 구급상자와 검 | 조사와 회복 | 자동 저장. 대화 중 일시정지. 첫 전투는 안전구간 뒤에 시작 |

6~7분에는 풍뎅이 하나가 느린 직선 공격을 한다. J 한 번의 베기, 한 걸음 비키기, 다시 베기로 첫 승리를 만든다. 11분 안에 새 능력으로 실제 길을 건너게 해 탐험 보상을 체험시킨다. 조작 안내는 성공하면 사라지고, 다음 새 행동은 이전 행동을 해본 뒤 한 개씩 제시한다.

## 적은 입력, 커지는 선택

| 입력 | 기본 기능 | 후반에도 유지되는 원칙 |
| --- | --- | --- |
| 이동 | WASD 또는 방향키 | 자유롭게 걸어 피할 수 있음. 조준을 위한 별도 마우스 조작 불필요 |
| J / 공격 버튼 | 현재 무기 공격 | 기본 검은 자동 연속 베기 가능. 가장 가까운 전방 표적에 약한 조준 보조 |
| Space / 회피 버튼 | 이동 방향 짧은 회피, 정지 시 바라보는 방향 | 사자의 서가 같은 회피의 통과 지형을 늘림. 추가 능력키 없음 |
| E / 조사 버튼 | 대화·획득·문·수레·봉인 | 가장 가까운 유효 대상 하나만 안내. 조사 실패로 자원 소모 없음 |
| Q / 무기 버튼 | 획득한 무기 순환, 선택 사용 | 1~3은 숙련자용 바로가기. 수첩·지도·정지는 보조 메뉴 |

초반 필수 학습은 이동+E, 이어 Space, 마지막 J 순서. Q는 리볼버를 받은 뒤 선택 안내한다. 모바일도 이동 패드+공격·회피·조사 3개를 주 조작으로 두고 무기는 작은 보조 선택으로 둔다. 수동 장전·콤보 입력·패링·달리기 키·유물별 단축키는 추가하지 않는다.

검으로 본편의 모든 필수 적을 상대할 수 있게 조정한다. 현재 프로토타입의 먹 망령 ‘지팡이만 유효’ 조건은 본 설계에서 제거 대상이다. 리볼버는 떨어져 안전하게 공격, 지팡이는 느린 관통·넓은 견제로 상황을 쉽게 만드는 선택이다. 탄약 파밍과 소모성 마나 대신 짧은 재사용 시간을 사용한다. 필수 장치는 E로 작동하며 특정 무기 교체를 요구하지 않는다.

천부인은 얻는 즉시 장비 슬롯에 고정, 심장적출검은 기존 검 슬롯의 강화 형태다. 최종전 시작 시 해당 슬롯을 자동 선택하고 아이콘 두 개가 빛난다. 이후 다른 무기를 선택하면 본체에 타격할 수 없다는 기존 조건은 유지하되, 검 복귀 안내와 보조 적 상대 용도를 명확하게 보여준다.

## 유물은 버튼 대신 세계를 바꾼다

| 획득 | 즉시 보이는 변화 | 한 번 더 쓰는 곳 |
| --- | --- | --- |
| 사자의 서 | 같은 회피로 물 위 짧은 틈을 건넘 | 안데스의 짧은 석교 간격, 런던 추격의 끊긴 발판 |
| 미노타우로스 도기 | 걸어온 실제 길에 실이 자동으로 남음 | 백룸 귀환, 마지막 홈즈의 진짜 발자국 비교 |
| 라마수 | 봉인문에서 E 한 번으로 개방 | 잭의 거울 통로 봉쇄, 열람실 귀환문 |
| 그림 두루마리 | 가까운 가짜 문이 흐려지고 숨은 흔적이 나타남 | 한국 진입, 고양이 발자국, 홈즈 추격 |
| 천부인 | 회피 뒤 가까운 환영과 노란 연결을 잠깐 고정 | 수집가 구출과 대성당 반격 |
| 아즈텍 심장적출검 | 같은 J가 드러난 지배 연결을 베어냄 | HAster 조종 해제, 하스터 최종전 |

각 능력은 획득 직후 위험 없는 짧은 통로에서 한 번 체험한다. 이후 이미 배운 것 두 가지만 조합하며, 새 규칙·새 적·새 조작을 같은 방에서 동시에 가르치지 않는다. 귀환 지름길은 끝까지 유지하고 잡몹 처치를 문 개방 조건으로 삼지 않는다.

## 퍼즐을 줄이고 머리 쓰는 즐거움은 남긴다

장면 순서 맞추기, 저울 수치 조합, 명령서 암호, 세 지역 잠금장치 왕복은 필수 진행에서 제외한다. 대신 보이는 목표에 접근하기, 예고된 공격 뒤로 이동하기, 눈앞의 장치를 E로 작동하기로 바꾼다. 신화 설명은 선택 수첩으로 옮긴다.

홈즈와의 첫 대결은 2분짜리 관찰 장면이다. 루팡이 관련 원본을 바로 옆에 펼치고, 플레이어가 같은 장면을 조사하면 홈즈의 거짓 재현이 벗겨진다. 이어 발자국이 남는 실제 출구로 걸어간다. Rhast 철자나 명령 시각을 외워 객관식 답을 고르게 하지 않는다. 틀린 문은 바로 되돌려 주며 진행 초기화·체력 벌점 없음. 머리 승부는 논리와 진실을 알아보는 경험으로 유지한다.

## 가벼운 개그의 위치

웃음은 캐릭터의 진지함과 이상한 상황 사이에서 생긴다. 관장 사망·Rhast 발견·HAster의 고백·최종 분리 장면에는 개그를 넣지 않는다. 문화·신앙·희생자를 희화화하지 않고 박물관 업무, 빌리의 허세, 루팡과 에블린의 직업 차이를 소재로 삼는다.

| 빌리 구조 | 폼 잡고 총을 돌리다 탄창 대신 낡은 전시 입장권이 떨어짐. 에블린이 말없이 주워 건넴 | 조작을 막지 않는 행동 개그 |
| 루팡이 문 개방 | 루팡: “잠긴 문에는 자신 있소.” 에블린이 바로 옆 ‘당기시오’를 본다 | 유능함을 완전히 깎지 않는 단발성 농담 |

| 마지막 귀환 | 위험을 지나 돌아왔는데 반납 기한 도장이 그대로 찍힘. 에블린이 조용히 날짜를 수정 | 일상으로 돌아온 여운, 최종전 중에는 사용 안 함 |

같은 대사는 반복 재생하지 않는다. 대사 한 번은 1~2줄, 걷는 중 독백은 입력을 막지 않는다. 농담을 봐야 보상을 주거나 정해진 시간 동안 기다리게 하지 않는다.

## 퀘스트와 난이도

- 빌리의 운송 기록 3장: 본편 동선 옆에 배치. E로 줍고 다음 거점 방문에서 전달. 보상은 리볼버 편의 강화. 필수 유물·필수 피해량을 보상으로 잠그지 않는다.
- 숨은 고양이: 두루마리 이후 열람실의 발자국으로 시작. 지하 보관실까지 짧게 따라가 왓슨의 유물을 얻음. 약 3~5분 선택 탐험. 최종전 전 돌아갈 수 있음을 안내하고, 수집가 진입 전에 선택 루트를 상기시킴.
- 잡몹은 피해서 지나갈 수 있다. 첫 적은 한 마리, 이후 2~3마리와 돌진·원거리의 조합으로 확장. 숫자와 체력을 계속 불려 난도를 올리지 않는다.
- 추격은 45~75초 단위의 구간으로 나누고 각 구간 끝 저장. 공격 준비를 초반 약 1초 이상 보여주고 익숙한 후반 패턴에서만 간격을 줄이는 안으로 시작한다.
- 대성당은 3단계, 단계별 45~60초 목표. 단계 완료를 저장하고 죽어도 현재 단계부터 재시작. 근성은 오래 때리기가 아니라 익숙한 행동을 끝까지 해내는 것으로 표현한다.
- 동일 구간 3회 실패 시 ‘예고 길게 / 받는 피해 감소’ 도움을 제안한다. 자동으로 몰래 난도를 바꾸지 않으며 사용해도 진엔딩 자격을 유지한다.

## 현재 게임과 구현 차이

현재 배포본은 19개 방의 압축 프로토타입이다. 아래는 **구현 예정**이며 이 문서 작성으로 게임에 적용된 것은 아니다.

1. 첫 6분의 행동별 안내와 안전한 회피 학습, 수레 조작·짧은 관계 연출.
2. 구역별 연결 장면과 새로운 전투 배치로 실제 플레이 밀도 확보.
3. 무기 단계별 지급·Q 순환·조준 보조·필수 적의 무기 면역 제거.
4. 유물 패시브/맥락 작동, 객관식 추리와 순서 퍼즐을 짧은 행동 장면으로 교체.
5. 거점 농담·고양이 추적·반복 대사 억제, 추격 구간 및 최종전 단계 저장.
6. 첫 플레이 관찰을 통해 50분 가설 검증. 현재 배포본이 50분이라고 홍보하지 않음.

## 검증과 조정 기준

처음 하는 플레이어 5명 이상을 관찰한다. 튜토리얼 완료 시각, 첫 자발적 회피/반격, 유물 획득 시각, 길을 못 찾은 시간, 사망·재시도, 무기 교체 횟수, 엔딩까지의 실제 시간을 기록한다. 소규모 관찰을 일반적 재미의 증명으로 해석하지 않는다.

- 첫 90초 안에 외부 설명 없이 이동·조사 성공, 6분 안에 회피로 첫 추격 탈출, 11분 안에 능력으로 막혔던 길 통과를 목표로 한다.
- 새로운 능력 뒤 60초 안에 효용을 체험. 필수 길에서 60초 넘게 헤매면 시각 단서와 동선을 먼저 수정한다.
- 일반 엔딩 중앙값 약 50분, 대부분 45~60분 목표. 40분 미만이면 새로운 짧은 상황을 추가하고, 60분 초과 원인이 왕복·읽기·반복 사망이면 해당 마찰을 줄인다.
- 재미 질문은 “재미있었나”만 묻지 않고 기억나는 회피·새 능력·웃음 장면과 지루했던 구간을 각각 듣는다. 공포가 깨졌다는 반응은 개그 위치와 빈도를 먼저 조정한다.

반대 관점: 자동 능력과 약한 퍼즐은 조작 부담을 줄이지만 발견·선택의 맛까지 사라질 수 있다. 그래서 이동 경로 선택, 선택 무기, 지름길과 고양이 탐험을 남긴다. 반대로 모든 지역에 새 시스템을 주면 50분 안에 배우기만 하게 된다. 신규 입력은 늘리지 않고 지역마다 기존 행동 한 가지를 다르게 쓰게 한다.
