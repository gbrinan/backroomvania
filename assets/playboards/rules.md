# 플레이 규칙 초안

확정 서사: [결정 정본](../../decisions/0005-hastur-finale.md). 이 문서는 시각 보드에서 시험할 구체 규칙 제안이다. 보드는 조작 가능한 게임 캡처가 아닌 플레이 스토리보드다.

| 구간 | 플레이어 행동 | 어려움·읽을 단서 | 실패·복구 |
| --- | --- | --- | --- |
| 한국 | 세 장치를 잇고 빛을 돌려 천부인 회수 | 호랑이 그림자 공격과 장치 조작 순서 결합. 바닥 줄무늬가 공격 전에 나타남 | 방 입구 재시도, 얻은 장치 단서는 유지 |
| 아즈텍·메소아메리카 | 의례 발판을 건너 심장적출검 회수 | 의례 수호자의 그림자와 무너지는 발판의 교차 타이밍 | 마지막 안전 발판 복귀, 필수 검 소실 없음 |
| 아시아 연결 | 그림 두루마리와 천부인으로 봉인 지름길 개방 | 중국 종각의 음 순서, 인도 회랑의 경로 반사 퍼즐은 추가 후보 | 단서 다시 보기와 초기화 가능 |
| 수집 관문 | 6종 소장품을 슬롯에 기록 | 누락 유물의 구역을 지도에 표시 | 보스 진입 전 장비 점검·귀환 가능 |
| 1차·머리 | 루팡의 카드 단서와 발자국·거울 모순으로 진짜 홈즈의 문 선택 | 닮은 문 세 개 중 둘은 환각. 단서 두 개가 참 문을 교차 확인 | 잘못 고르면 짧은 전투 후 분기점 복귀. 정답 고정 학습 가능 |
| 2차·컨트롤 | 물웅덩이 흔적을 쫓고 예고된 공격 회피·반격 | 분신은 물에 흔적을 남기지 않음. 루팡이 한 갈림길 봉쇄 | 구간별 재시작, 초기 박물관부터 반복하지 않음 |
| 3차·근성 | 환각 파동을 피하고 노출되는 핵을 반복 공략 | 체력만 큰 보스보다 세 패턴 조합과 자원 관리. 루팡이 환각 거울 하나를 고정 | 완료한 봉인 단계 보존 후보. 무작위 즉사·무예고 공격 제외 |
| 타격 조건 | 천부인과 심장검 동시 장비, 천부인으로 환각 외피 해제 후 검 타격 | 일반 무기는 외피에 0 피해와 뚜렷한 방어 효과. 장비 상태 UI 표시 | 전투 중 장비 변경 가능, 필수 장비는 소모·판매 불가 |
| 숨은 고양이 | 발자국·책장 너머 눈빛·울음의 세 단서로 비밀 방 찾기 | 메인 동선 밖이지만 시간 제한 없음 | 최종전 전 박물관 귀환 가능 |
| 진엔딩 | 왓슨 유물로 홈즈의 기억을 깨우고 분리된 하스터만 공격 | 홈즈는 적 표식 제거, 하스터는 노란 핵 유지. 둘의 실루엣 분리 | 유물은 소모되지 않음, 최종 분기 전 저장 |

난도는 추론·반응·지속 수행에서 나오게 한다. 긴 체력 깎기로 근성을 표현하면 반복 피로만 커지므로 봉인 3단계를 학습·달성하는 방식으로 제안한다. 타이밍·데미지·체력 수치는 실제 플레이테스트에서 결정한다.

## 보드 검토 메모

천부인의 도상은 아직 통일 전이다. 추리 보드 아래 소품 아이콘은 수집 관문에 필요한 6종 목록이 아니며, 수집 조건은 결정 문서가 정본이다. 진엔딩 보드 마지막의 추가 회색 코트 인물은 생성 오류로, 실제 장면의 등장인물은 주인공·각성 홈즈·루팡·하스터 네 명이다. 이미지의 데미지와 체력 수치는 예시다.

정정: 심장검은 아즈텍의 심장적출검이다. 남미의 별도 탐험 구역은 유지하되 보상을 다시 정한다. 기존 보드의 남미 획득 장면과 장검 외형은 폐기된 제안이며 새 설정의 근거로 사용하지 않는다.
