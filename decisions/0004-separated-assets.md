# 0004: 여성 기록복원사와 분리 자산

상태: 사용자 확정, 2026-09-12.

주인공은 여성 기록복원사이며 검·리볼버·유물 지팡이 3종을 사용한다. 이름 에블린 베일은 여전히 가칭이다. 대화·컷신용 인물 시트, 인물 없는 배경, 게임플레이용 2D 스프라이트를 분리한다.

첫 제작은 주인공·빌리·이발사 캐릭터 시트 3장, 빅벤·런던 브릿지·이집트실 배경 3장, 주인공 4방향 걷기와 무기별 동작 시트 4장이다. 동작별 4프레임은 제작 초안이며 전투 타이밍은 미확정이다.

무기 동작을 몸과 함께 생성해 손과 무기의 관계를 우선 확인한다. 독립 무기 레이어는 프레임별 소켓 정렬을 검증한 뒤 분리한다. 생성된 시트의 정렬·방향·투명도·연속성은 실제 결과로 검사하고, 미달한 항목은 엔진 투입 가능으로 표기하지 않는다.
