# 0007: 긴 중반과 흰 옷의 수집가

상태: 사용자 확정, 2026-09-12.

일상·관장 사망·첫 추격은 intro다. 기존 공간을 활용하는 긴 중반 탐험이 필요하다. 모든 사건의 범인으로 의심받던 Trash는 흰 옷의 수집가이며, 종반에 홈즈에게 조종당하고 있었음이 드러난다. Trash의 정체는 HAster다.

사용자 추가 답변에 따라 HAster는 황색의 왕 하스터(Hastur)와 별개의 인물이다. 홈즈에게 조종당하는 인물 HAster와 홈즈 안의 최종 적 Hastur를 합치지 않는다. HAster의 인간 설정·실명 사용 방식·조종 수단 등은 서사 제안이다.

이 결정은 full-story v1의 중반 Trash 구출과 단순 피해자 해명을 대체한다. v2는 같은 파일에서 갱신하며 v1은 Git 이력으로만 남긴다. 구체 장면과 Rhast 해독 방식은 제안 상태다.
