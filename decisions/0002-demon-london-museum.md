# 0002 — 마계화된 런던과 신화의 박물관

- 상태: 사용자 요구 범위 확정, 세부 설계 제안.
- 근거: 사용자가 셜록 홈즈 시대의 마계화된 런던, 빌리 더 키드·면도날 살인마, 빅벤·런던 브릿지·대영박물관, 문화별 유물의 신화 적과 방 탈출을 요청했다.
- 결정: 기존 탑다운 2D 스프라이트와 능력 기반 재탐험을 유지하고 주 무대를 대영박물관으로 변경한다.
- 대체: 초기 노란 벽지 백룸과 익명 휴게실 구상은 박물관의 반복 전시실과 원형 열람실로 구체화한다.
- 미확정: 1888년, 기록복원사 주인공, 빌리 동맹, 독자 살인마, 네 구역과 보상은 기획 제안이다.
- 영향: 유물과 신화의 근거를 조사하고 역사적 구조·게임의 공간 왜곡을 구분한다. 이미지는 Higgsfield로 제작한다.
