# 0001 — 성검전설 3식 탑다운

- 상태: 확정, 2026-09-12.
- 문제: 2D 스프라이트 게임의 시점과 탐험 공간 표현.
- 결정: 성검전설 3식 탑다운을 사용한다.
- 근거: 사용자가 ‘성검전설 3식 탑다운’으로 명시적으로 선택했다.
- 검토한 대안: 횡스크롤, Legend of Mana식 바닥 평면 이동.
- 영향: 방과 복도의 평면 연결을 중심으로 맵을 설계한다. 방향별 스프라이트와 벽 뒤 가림을 검토한다.
- 범위: 시점 선택만 확정한다. 원작의 전투·파티·성장 시스템과 플랫폼·엔진은 별도 결정한다.
- 재검토: 사용자가 시점 변경을 요청하거나 프로토타입에서 공간 판독 문제가 확인되면 대안을 논의한다.
