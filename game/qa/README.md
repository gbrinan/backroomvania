# 실행 검증

## 자동 검사

`node --test game/qa/game.test.mjs`: 14개 통과. 충돌·전역 상호작용 도달성·유물/무기 잠금·회피·저장/재시작·반전/엔딩·잡몹 회피 이동·퀘스트 보상·지름길.

## 실제 브라우저

Playwright + 설치된 Edge, 실제 Canvas 렌더와 키보드/버튼 입력으로 실행했다.

- `browser.cjs`: 정리 두 점부터 관장 대화, 거울, Rhast, 잭 추격, 수레, 열람실까지 실제 입력. 이어서 저장 fixture로 19개 방 전부 캡처. 첫 진엔딩 화면은 bossDown fixture로 시작했다.
- `combat-browser.cjs`: 리볼버 공격, Esc 일시정지/복귀, 실제 사망, 체크포인트 재시작, 최종전 실전 입력 및 모바일 타이틀.
- `quest-browser.cjs`: 중국 회랑의 세 번째 기록을 공격 없이 수집, 잡몹을 남기고 열람실 이동, 빌리 제출 및 보상 저장. 첫 두 기록은 fixture.
- `refresh.cjs`: 마지막 소스 상태의 19개 방과 엔딩/타이틀 반응형 화면 재캡처.
- `browser-report.json`, `combat-report.json`, `quest-report.json`, `fresh-captures.json`: 실행 범위와 결과.

## 시각 검토

1280 / 768 / 375px 캡처. 직접 확인과 독립 검토에서 발견된 좁은 화면 무기 줄바꿈, 타이틀 높이, 데스크톱 한글 조사 분리를 수정했다. 이전 `dialog-375.png`는 수정 전 비교 자료이며 최종 화면은 `play-375.png` 및 `ending-375.png`이다.

## 한계

모든 장편 스토리를 무보조 연속 플레이한 검증은 아니다. 각 방의 전체 전투 밸런스, 모바일 실기기 장시간 조작, 음향 취향, 플레이 재미와 장편 난이도는 사람의 플레이테스트가 필요하다. Lighthouse 점수는 측정하지 않았다. 반응형 캡처는 모바일 기기 실측과 구분한다.
