# 제13종의 밤 — 첫 플레이 버전

기존 장편 기획의 흐름을 압축한 브라우저 탑다운 액션 게임이다. 정식 출시판이나 완성된 아트 빌드는 아니다.

## 실행

Node.js 22 이상이 설치된 환경에서 저장소 루트에서 실행:

```sh
node game/server.mjs
```

브라우저에서 <http://127.0.0.1:4173/game/>를 연다. 외부 패키지 설치는 필요 없다. 서버는 로컬 주소에만 바인딩한다. 포트 변경은 PORT 환경 변수로 지정한다. HTML 파일을 직접 열면 ES modules가 브라우저의 파일 보안 정책에 막힐 수 있으므로 서버를 사용한다.

## 조작

| 조작 | 입력 |
| --- | --- |
| 이동 | WASD / 방향키 |
| 조사·문·유물 | E |
| 공격 | J 누르기 / 게임 화면 누르기 |
| 회피 | Space (재사용 1.2초) |
| 검·리볼버·지팡이 | 1 / 2 / 3 |
| 지도 | M / 지도 버튼 |
| 일시정지 | Esc / 일시정지 버튼 |

좁은 화면에서는 이동·조사·공격·회피 버튼도 제공한다. 음향은 우측 위에서 켠다. 공격은 가까운 적을 자동 조준한다.

## 플레이 범위

- 일상 유물 정리, 관장과 Trash 대화, 지하 거울, Rhast 조사, 잭 더 리퍼 회피, 안전한 열람실.
- 19개 방. 이집트·그리스·아시리아·중국·인도·일본·한국·안데스·아즈텍, 침수 백룸, 런던 브리지·빅벤·대성당.
- 근접 검, 원거리 리볼버, 먹의 망령에 필요한 지팡이. 예고 공격, 추적 경로 탐색, 회피 무적 시간.
- 여섯 유물로 순차 개방되는 통로와 지름길. 천부인·아즈텍 심장적출검 자동 장비 후 1번 무기로 최종 보스 타격.
- 흰 수집가 Trash = 별개 인간 HAster라는 반전. 홈즈의 증거 대결, 추격, 최종 전투.
- 두루마리 획득 후 열람실에 나타나는 고양이로 왓슨의 유물을 얻으면 진엔딩.
- 방 진입·유물·주요 단서 자동 저장. 사망 시 해당 방 체크포인트로 복귀. 브라우저별 로컬 저장이며 계정 동기화 없음.

## 아직 정식 제작이 필요한 부분

장편 중반의 길이, 보스별 고유 애니메이션, 생성 원화의 정식 스프라이트 변환, 컷신 인물 원화, 문화별 세부 고증/적 디자인, 음향·난이도 조정은 후속 제작 대상이다. 현재 캐릭터·적·타일은 코드로 제작한 임시 픽셀 아트다. 자동 테스트는 재미나 최종 난이도를 보증하지 않는다. 화면 읽기 프로그램으로 실시간 공간 전투를 플레이하는 기능은 제공하지 않는다.

## 검증

```sh
node --test game/qa/game.test.mjs
```

브라우저 QA 스크립트는 Playwright와 Edge를 사용하며 테스트 환경의 번들 경로를 참조한다. 실행 증거와 범위는 [qa/README.md](qa/README.md)를 참조한다.

## 잡몹을 피하는 탐험과 퀘스트

잡몹은 평소 순찰하다 가까이 오면 추격한다. 문을 지나려면 잡몹을 모두 죽일 필요가 없다. 유물 앞의 ◆ 표시가 있는 수호자만 해당 유물을 봉인한다. 수호자를 쓰러뜨린 후 남은 잡몹은 피하고 유물을 챙겨도 된다.

열람실에서 빌리의 의뢰를 받아 이집트관·침수 백룸·중국 회랑의 운송 기록을 3장 모아 돌아오면 리볼버 사격 간격이 0.52초에서 0.34초로 줄어든다. 의뢰는 전투 없이 완료 가능하다. 사자의 서는 이집트→배수실, 도기는 그리스→열람실, 라마수는 아시리아→동방 회랑 지름길도 연다.

## 배경 음악

[고딕 다크 판타지 BGM](music/README.md) 두 곡을 포함한다. 소리 켜기를 누르면 탐험곡이 재생되며 추격·최종전에서는 긴장감 있는 변주로 전환한다. 업데이트 후 새로고침이 필요하다.
