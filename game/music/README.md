# Gothic dark fantasy score

독자 작곡한 신시사이저 배경음. 외부 곡·샘플·생성 음성은 사용하지 않았다.

- `the-unwritten-archive.wav`: 기록되지 않은 장서고. D minor 중심, 60 BPM, 32초 스테레오 루프. 파이프 오르간 음색, 낮은 현악형 패드, 금속성 종과 긴 잔향. 일반 탐험·열람실·일상 도입용.
- `the-thirteenth-bell.wav`: 열세 번째 종. 90 BPM, 약 21.33초 루프. 같은 화성을 빠른 저음 반복과 타격음으로 변주. 잭 추격·런던 브리지·빅벤·최종전용.

`node game/music/compose.mjs`로 32kHz/16-bit stereo WAV를 재현한다. 루프 경계에는 음과 잔향을 순환 합산했다. 게임의 소리 버튼을 켜면 재생하며, 장면 전환은 1.5초 페이드 인/0.8초 페이드 아웃이다. 효과음보다 낮은 음량으로 믹스한다.

현재는 합성 악기 시안이며 실제 관현악 녹음은 아니다. 헤드폰·스피커에서의 취향과 장시간 반복 청취 평가는 후속 조정 대상이다.
